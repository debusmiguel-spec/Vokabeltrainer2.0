VOKABELTRAINER V2 - ANDROID/PWA

GitHub Pages:
1. Entpacke diese ZIP-Datei.
2. Ersetze in deinem bestehenden GitHub-Repository die alten App-Dateien durch:
   index.html
   manifest.webmanifest
   service-worker.js
   icon.svg
3. Commit changes.
4. GitHub Pages veröffentlicht die neue Version automatisch.
5. Öffne die HTTPS-Adresse auf Android in Chrome.
6. Wähle "App installieren" oder "Zum Startbildschirm hinzufügen".

Hinweis:
Browser-/PWA-Daten werden lokal auf dem jeweiligen Gerät gespeichert.
